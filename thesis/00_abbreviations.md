# Обозначения и сокращения

| Обозначение | Расшифровка |
| --- | --- |
| APDEX | Application Performance Index — индекс производительности приложения |
| API | Application Programming Interface — программный интерфейс приложения |
| CI/CD | Continuous Integration / Continuous Delivery — непрерывная интеграция и доставка |
| CPU | Central Processing Unit — центральный процессор |
| CRUD | Create, Read, Update, Delete — базовые операции с данными |
| DSL | Domain-Specific Language — предметно-ориентированный язык |
| GIL | Global Interpreter Lock — глобальная блокировка интерпретатора Python |
| HTTP | HyperText Transfer Protocol — протокол передачи гипертекста |
| HTML | HyperText Markup Language — язык разметки гипертекста |
| JSON | JavaScript Object Notation — формат представления данных |
| КИП | Корпоративный инструментальный пакет (1С) |
| ORM | Object-Relational Mapping — объектно-реляционное отображение |
| p50 | 50-й перцентиль латентности (медиана) |
| p95 | 95-й перцентиль латентности |
| p99 | 99-й перцентиль латентности |
| PromQL | Prometheus Query Language — язык запросов Prometheus |
| REST | Representational State Transfer — архитектурный стиль API |
| RPS | Requests Per Second — запросов в секунду (пропускная способность) |
| SLA | Service Level Agreement — соглашение об уровне обслуживания |
| SLO | Service Level Objective — целевой показатель уровня обслуживания |
| SQL | Structured Query Language — язык структурированных запросов |
| TLS | Transport Layer Security — безопасность транспортного уровня |
| TPS | Transactions Per Second — транзакций в секунду |
| TTL | Time To Live — время жизни (для записи метрик) |
| URL | Uniform Resource Locator — унифицированный указатель ресурса |
| VU | Virtual User — виртуальный пользователь |
| WSGI | Web Server Gateway Interface — интерфейс шлюза веб-сервера |
| YAML | YAML Ain't Markup Language — формат сериализации данных |
